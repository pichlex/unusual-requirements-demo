# Haptic Lab v0.3

This revision adds a two-dimensional tactile field and removes diagnostic UI from the public demo.

## Changes

- XY touch field with grid-crossing feedback on iPhone
- mouse and trackpad support on desktop
- cleaner copy with technical status streams hidden
- calmer card styling and reduced mobile compositing work
- existing sliders, tabs, button, toggle and dial retained

The current browser technique still relies on a rendered native Safari switch. Treat it as experimental and test on physical devices.
